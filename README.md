# ORBIT — Autonomous Agent Manager

ORBIT is a multi-agent orchestration platform that turns a high-level goal into a coordinated workflow of specialized AI agents.

Instead of asking one AI to do everything, ORBIT uses a Manager agent to plan work, assign tasks based on capabilities, monitor execution, handle failures, review results, replan when necessary, and produce a final project deliverable.

## Features

* LLM-powered project planning
* Capability-based agent assignment
* Dependency-aware task scheduling
* Specialized agents for research, coding, backend implementation, and review
* Agent-to-agent context sharing
* Automatic retry and agent reassignment
* LLM-powered code review and rework cycles
* Manager-driven project replanning
* Real-time WebSocket event streaming
* Live React Flow visualization
* Generated project artifacts and ZIP downloads
* Final project report generated by the Manager

## Architecture

```text
User Goal
   ↓
Manager
   ↓
LLM Planner
   ↓
Structured Task Graph
   ↓
Agent Registry
   ↓
Scheduler
   ↓
Specialized Agents
   ↓
Results / Artifacts
   ↓
Reviewer
   ↓
Manager
   ↓
Replan or Complete
   ↓
Final Deliverable
```

ORBIT keeps the LLM responsible for reasoning and planning while the application controls execution, scheduling, validation, retries, and agent lifecycle.

## Running Locally

### Backend

Activate the virtual environment and install dependencies:

```bash
pip install -r requirements.txt
```

Create `backend/.env`:

```env
OPENAI_API_KEY=your_api_key_here
```

Start FastAPI:

```bash
python -m uvicorn app.main:app --reload
```

### Frontend

From the frontend directory:

```bash
npm install
npm run dev
```

Open the local Vite URL shown in the terminal.

## Example

Give ORBIT a goal such as:

```text
Build a REST API for managing projects with authentication,
PostgreSQL, Docker, and tests.
```

ORBIT can then:

1. Generate a task plan.
2. Assign tasks to appropriate agents.
3. Execute tasks and share results.
4. Recover from failures.
5. Review generated work.
6. Rework or replan when needed.
7. Produce a final report and downloadable project.

## Current Scope

ORBIT is currently designed as a lightweight, one-shot orchestration system. Project state is kept in memory rather than persisted to a database, while generated artifacts can be downloaded as a project bundle.

## Future Improvements

Potential future work includes richer artifact inspection, more specialized agents, improved task visualization, persistent project history, and deployment as a public web application.
